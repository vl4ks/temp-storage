# 1. Пользователь - физ.лицо, которое имеет доступ к системе.
 1) Логин - универсальный идентификатор пользователя
 2) Пароль - набор символов для входа в систему
 3) Роль - определяет роль пользователя в системе и его перечень прав, может быть: иммигрант/администратор/госслужащий

# 2. Параметр - определяет характеристики конкретного пользователя
 1) Название - название параметра(ИНН, ФИО, кол-во детей и т.д.)
 2) Значения - значение параметра

# 3. Заявка - конкретное заявление осуществления услуги с которым взаимодействует пользователь 
 1) Дата подачи - дата подачи заявления
 2) Дата получения - дата получения результата заявления
 3) Статус - статус заявления
 4) Комментарий - комментарий по заявлению от госслужащего

# 4. Услуга - услуга, с которой могут взаимодействовать пользователи
 1) Название - название услуги

# 5. Дорожная карта - перечень действий для получения конкретной услуги
 1) Описание - описание действий для получения услуги
 
# 6. Правило - условия, которые регламентируют получение конкретной услуги
 1) Название - название правила
 2) Референсное значение - конкретное значение на которое следует ориентироваться
 3) Оператор сравнения - определяет то, как нужно ориентироваться на референсное значение
