# Сущности

## Аккаунт
**Описание:** физ.лицо, которое имеет доступ к системе.

**Атрибуты:**
  1) **Логин** - универсальный идентификатор пользователя
  2) **Пароль** - набор символов для входа в систему
  3) **Роль** - определяет роль пользователя в системе и его перечень прав, может быть: иммигрант/администратор/госслужащий
  4) **Фамилия** - фамилия пользователя
  5) **Имя** - имя пользователя
  6) **Отчество** - отчество пользователя

## Пользователь
**Описание:** иностранный гражданин, который использует систему с целью получения той или иной услуги.

**Атрибуты:**
  1) **ИНН** - номер ИНН пользователя
  2) **Номер паспорта** - номер паспорта пользователя
  3) **Серия паспорта** - серия паспорта пользователя
  4) **Дата рождения** - дата рождения пользователя
  5) **Гражданство** - гражданство пользователя
  6) **Цель визита** - цель визита пользователя на территорию РФ
  7) **Номер телефона** - номер телефона пользователя

## Админ
**Описание:** администратор информационной системы.

## Госслужащий
**Описание:** госслужащий, который обрабатывает заявку.

## Услуга
**Описание:** конкретная услуга, которую оказывает государство иностранному гражданину.

**Атрибуты:**
  1) **Название** - название услуги
  2) **Описание** - описание услуги
  3) **Срок действия** - кол-во дней, которое действует услуга

## Заявка
**Описание:** конкретная заявка пользователя на получение какой-либо услуги.

**Атрибуты:**
  1) **Дата подачи** - дата подачи заявления
  2) **Дата получения** - дата получения результата заявления
  3) **Ожидаемая дата получения** - ожидаемая дата получения результата заявления
  4) **Комментарий** - комментарий, оставленный госслужащим по заявлению
  5) **Статус** - статус заявления

## Правило
**Описание:** условия, которые регламентируют получение конкретной услуги.

**Атрибуты:**
  1) **Название** - название правила
  2) **Референсное значение** - конкретное значение, на которое следует ориентироваться
  3) **Значение пользователя** - значение, с которым сравнивается референсное значение
  4) **Оператор сравнения** - определяет то, как нужно ориентироваться на референсное значение

## Параметр
**Описание** параметр, который используется для определения значения правила
**Атрибуты**
  1) **Значение** - значение, которое в себе содержит параметр

# Связи
1) **Аккаунт - Пользователь**: связь `1 к 1`, у одного пользователя один аккаунт.
2) **Аккаунт - Админ**: связь `1 к 1`, у одного админа один аккаунт.
3) **Аккаунт - Госслужащий**: связь `1 к 1`, у одного госслужащего один аккаунт.
4) **Пользователь - Заявка**: связь `1 к М`, один пользователь может оформить много заявлений
5) **Админ - Услуга**: связь `1 к М`, один Администратор может редактировать много услуг.
6) **Госслужащий - Заявка**: связь `1 к М`, один госслужащий обрабатывает много заявок.
7) **Услуга - Правило**: связь `1 к М`, одна услуга содержит в себе много правил.
8) **Услуга - Заявка**: связь `1 к М`, по одной услуге создается много заявок.
9) **Правило - Параметр**: связь `1 к М`, по одному правило содержится несколько параметров.
